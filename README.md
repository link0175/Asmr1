# ASMR · Эпизод 1: Ночная трасса

Интерактивный фильм от первого лица в мультяшном комикс-стиле. Ночь, трасса, машина в кювете, фонарик и выбор игрока.
Вся графика рисуется кодом, все звуки (мотор, сверчки, ветер, совы, шаги) синтезируются — файлов нет, работает без интернета.

## Как получить APK

**Вариант 1. GitHub, без установки программ**
1. Создай новый репозиторий на github.com и загрузи туда содержимое этой папки (Add file → Upload files).
2. Открой вкладку **Actions** и дождись, пока сборка «Build APK» станет зелёной (около 3–5 минут).
3. Открой эту сборку и скачай внизу **ASMR-apk**. Внутри лежит `app-debug.apk`.
4. Перекинь APK на телефон и установи (разреши «установку из неизвестных источников»).

**Вариант 2. Android Studio**
Открой папку через File → Open, дождись синхронизации Gradle и нажми Build → Build APK(s).

## Где менять игру
Вся игра находится в `app/src/main/assets/index.html`.
